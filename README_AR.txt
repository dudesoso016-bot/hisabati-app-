حساباتي الشخصية — نسخة PWA قابلة للتثبيت على Android

محتويات المجلد:
- index.html: التطبيق
- manifest.json: اسم التطبيق وأيقونته وإعدادات التثبيت
- sw.js: تخزين ملفات التطبيق لفتحها دون اتصال بعد أول زيارة
- icons/: أيقونات التطبيق

مهم للخصوصية:
- التطبيق لا يرسل سجلاتك المالية إلى خادم؛ البيانات تبقى في localStorage داخل المتصفح على الجهاز.
- رابط التطبيق مستضاف على الإنترنت، ويمكن للآخرين فتح التطبيق نفسه، لكن هذا لا يمنحهم تلقائيًا الوصول إلى localStorage الخاص بك.
- لا تضع سجلات مالية أو نسخ احتياطية في ملفات الموقع أو مستودع الكود.
- بيانات اللابتوب لا تنتقل تلقائيًا إلى الهاتف. صدّر نسخة JSON من اللابتوب ثم استوردها على الهاتف بعد فتح التطبيق هناك.
- احتفظ بنسخة احتياطية في مكان آمن؛ مسح بيانات الموقع/المتصفح قد يحذف السجلات.
- لا تستخدم جهازًا مشتركًا لتسجيل معلومات مالية خاصة.

النشر المجاني عبر GitHub Pages:
1. فك ضغط ZIP.
2. أنشئ حسابًا على GitHub إذا لم يكن لديك حساب.
3. أنشئ مستودعًا جديدًا (New repository) باسم مثل hisabati-app.
4. إذا استخدمت GitHub Free، اجعل المستودع Public عند إعداد GitHub Pages.
5. ارفع محتويات هذا المجلد إلى جذر المستودع، بحيث يكون index.html في الجذر وليس داخل مجلد إضافي.
6. افتح Settings ثم Pages.
7. في Build and deployment اختر Deploy from a branch، ثم الفرع main والمجلد /(root)، واضغط Save.
8. انتظر نشر الموقع. افتح رابط https://USERNAME.github.io/hisabati-app/ (استبدل USERNAME باسم حسابك).
9. افتح الرابط من هاتف Android في Google Chrome، وانتظر تحميل الصفحة مرة أولى مع اتصال الإنترنت.
10. اضغط قائمة Chrome ⋮ ثم Install app / تثبيت التطبيق، أو Add to Home screen / إضافة إلى الشاشة الرئيسية. قد تختلف التسمية حسب الهاتف.
11. افتح التطبيق من الأيقونة واختبر إضافة عملية صغيرة ثم احذفها.

بديل النشر:
يمكن استخدام أي استضافة ملفات ثابتة مجانية تدعم HTTPS. لا ترفع ملفات النسخ الاحتياطية أو بياناتك الشخصية إلى الاستضافة.

اختبار العمل دون اتصال:
بعد فتح الموقع أول مرة وهو متصل بالإنترنت، افتح التطبيق مرة أخرى ثم جرّب وضع الطيران. قد يحتاج Service Worker بضع ثوانٍ لإكمال التخزين في أول زيارة.
